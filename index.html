The algorithms

  1. Breadth-first search

    Explores in rings: every cell one step away, then two, then three. A queue keeps the order. The first route to reach the goal has the fewest steps, but BFS counts mud as one step, so it walks straight through it.

  2. Dijkstra's algorithm

    Always expands the cheapest cell found so far, using a priority queue (a binary heap). Costs add up correctly, so it returns the lowest-cost path and goes around mud when that is cheaper. It searches evenly in every direction.

  3. A* search

    Dijkstra plus a sense of direction. Each cell is ranked by cost so far plus an estimate of what is left, the Manhattan distance to the goal. The estimate never overshoots, so the path is still the cheapest, but cells leading away from the goal are rarely touched. Run it next to Dijkstra with Compare to see the difference.

Chase mode

The chaser C runs A* to the target T and walks the path. Each time the target moves or a wall changes, it plans again; the dashed line is its current plan. Mud slows both of you. Pick Flee AI to watch a target that runs on its own, choosing the cell the chaser would take longest to reach.

Maps

Maze builds a perfect maze with the recursive backtracker. Export JSON saves the board to a file and Import JSON loads one back, so you can share a tricky map.
